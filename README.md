# Your Agent Starter

一份丟給 AI 就會自己跑起來的腳本，帶你把 AI 從「每次都要重講一遍的工具」變成「認得你的助理」。

不用寫程式。你只要回答幾個問題。

---

## 這是什麼

你有沒有發現，每次開新對話都要重新跟 AI 解釋一次自己是誰、在做什麼、想要什麼樣的回答？

那不是 AI 笨，是**它沒有一個地方記得你是誰**。

這份腳本會訪談你，把你的答案寫成一份檔案。之後 AI 每次開始工作，都會先把那份檔案讀一遍——所以它記得。

## 怎麼用

**1. 下載 [`agent-starter.md`](agent-starter.md)**

**2. 打開你的 AI**（Claude Code 或 Codex 的桌面版都可以）

**3. 指定一個資料夾**給它工作——建議開一個新的空資料夾，例如 `my-agent`

**4. 把檔案丟進對話**，然後說：

```
照這份文件做
```

接下來它會問你問題，你回答就好。

## 它會問你什麼

一次問一題，總共五題：

| | 問什麼 | 為什麼問 |
|---|---|---|
| 1 | 你想怎麼稱呼我？ | 名字是你給的，這個助理才是你的 |
| 2 | 你是做什麼的？ | 它要知道你的工作長什麼樣 |
| 3 | 什麼時候該反駁你？什麼時候閉嘴照做？ | **最重要的一題**——決定它是唯唯諾諾還是真的幫得上忙 |
| 4 | 我做什麼會讓你煩？ | 你的地雷 |
| 5 | 回話該長什麼樣？ | 長短、語氣、格式 |

問完它會先整理給你確認，你點頭才會寫檔。

## 三個階段

腳本分三段，你可以只做第一段——那是最重要的一步。

| | 做什麼 | 產出 |
|---|---|---|
| **① 認識你** | 訪談五題 | 一份「我該怎麼跟你合作」的檔案 |
| **② 給它記憶** | 建資料夾、每日日誌、記下你的檔案都放哪 | 它記得住跨天的事 |
| **③ 給它能力** | 把重複的事變成招式 | 它會做你教它的流程 |

跑完第一段就停下來，用一個禮拜，再決定要不要往下。

## 跑完之後，最重要的一件事

**關掉對話，重新開一個。**

然後隨便問它一句話——你會發現它講話的方式變了。

因為它每次開始工作，都會先讀那份檔案。

## 常見問題

**我原本就有 CLAUDE.md，會被蓋掉嗎？**
不會。腳本會先讀一次，把新內容接在後面，用標記包起來。

**Claude Code 跟 Codex 都能用嗎？**
可以。腳本會自己判斷環境，寫成對應的檔名（`CLAUDE.md` 或 `AGENTS.md`）。

**資料夾可以用中文名字嗎？**
建議不要。多數時候能用，但一旦出問題（某個工具不支援、換到 Windows、上傳到 git）會很難查。用英文最保險。

**每次都要重貼檔案路徑給 AI，很煩怎麼辦？**
第二階段會建一份「我的東西都放哪」清單。你講一次，它記下來——之後說「幫我看某某專案」它就知道去哪找。

**這份檔案寫完就結束了嗎？**
不是。你每次覺得「怎麼又來了」的時候，就是它該長大的時候——跟 AI 說「把這條加進規矩」就好。
