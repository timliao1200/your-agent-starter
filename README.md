# Your Agent Starter

把 AI 從「每次都要重講一遍的工具」變成「認得你的助理」。

不用寫程式，也不用打指令。你只要回答幾個問題。

---

## 這是什麼

你有沒有發現，每次開新對話都要重新跟 AI 解釋一次自己是誰、在做什麼、想要什麼樣的回答？

那不是 AI 笨，是**它沒有一個地方記得你是誰**。

這份檔案會讓 AI 訪談你，把你的答案寫成一份規則檔。之後它每次開始工作都會先讀一遍——所以它記得。

## 怎麼用

**1. 下載你需要的那一個**

| 你用的 | 下載這個 |
|---|---|
| Claude Code | [`CLAUDE.md`](CLAUDE.md) |
| Codex | [`AGENTS.md`](AGENTS.md) |
| 不確定 | 兩個都下載 |

> 在 GitHub 上點檔名 → 右上角的下載圖示（Download raw file）

**2. 把檔案放進任何一個資料夾**，然後在那裡打開你的 AI

隨便哪個資料夾都可以——新建一個空的最好，桌面上也行。**這只是暫時的落腳處**，等一下工程師會幫你搬家。

**3. 隨便說一句話**

就這樣。**駐點 Agent 工程師會自己出現。**

### 接下來會發生什麼

**tt** 會出現——他是 Tim 派去的駐點 Agent 工程師，會待在你電腦裡直到設定完成。

整趟七段，**每一段結束他都會問你要不要繼續**，可以隨時喊停：

| | tt 幫你做什麼 | 你會學到 | 做完你會有 |
|---|---|---|---|
| **0** | 問你的英文名，決定資料夾放哪，建好家 | 分身要有自己的資料夾 | 一個 `你的名字-agent` |
| **1** | 訪談五題，**出一個小挑戰讓你自己改** | **改幾行字，AI 講話就變了** | 你的規則檔 |
| **2** | 帶你看那些隱藏資料夾，接上全域 | 廠商把你的身份鎖在哪裡 | 在任何資料夾都認得你 |
| **3** | 裝第一個 MCP，當場用一次，**寫成流程** | 規則檔只留索引，內容放外面 | 它會讀 YouTube，＋ `workflows/` 第一條流程 |
| **4** | 建記憶系統 | **AI 的記憶其實在你硬碟裡** | 日誌、摘要、待辦 |
| **5** | 教你 LLM Wiki，裝 Obsidian | 知識為什麼要放在規則檔外面 | 看得見的知識網 |
| **6** | 幫你讀第一份東西、示範一次健檢 | **收料要帶你自己的看法** | 第一批內容 ＋ 一套健檢規矩 |

### 中途走掉也沒關係

tt 會在你的資料夾裡留兩份東西：**`onboarding.md`**（進度表）跟 **`tt-script.md`**（他自己的腳本）。

你做到第三段就去忙了，兩個禮拜後回來，**在那個資料夾開 AI 就好**——
它會自己問你要不要接著做。**不用重新下載，也不用重講。**

跑完之後那份進度表留著，變成**你自己的學習紀錄**——每一段學到什麼都寫在裡面。

**第 0 段結束要換一次資料夾**——那是唯一需要你動手的地方，tt 會給你一句話複製貼上。

### 如果它沒有自己開始

少數情況它會先問你要做什麼。跟它說一句就好：

```
照這份文件做
```

## 它會問你什麼

一次問一題，總共五題：

| | 問什麼 | 為什麼問 |
|---|---|---|
| 1 | 你想怎麼稱呼我？ | 名字是你給的，這個助理才是你的 |
| 2 | 你是做什麼的？ | 它要知道你的工作長什麼樣 |
| 3 | 什麼時候該反駁你？什麼時候閉嘴照做？ | **最重要的一題**——決定它是唯唯諾諾還是真的幫得上忙 |
| 4 | 我做什麼會讓你煩？ | 你的地雷 |
| 5 | 回話該長什麼樣？ | 長短、語氣、格式 |

問完它會先整理給你確認，你點頭才會寫檔。

**寫完之後，你下載的那份起始腳本會被換掉**——變成你自己的規則檔。它的任務就結束了。

## 三個階段

可以只做第一段——那是最重要的一步。

| | 做什麼 | 產出 |
|---|---|---|
| **① 認識你** | 訪談五題 | 一份「我該怎麼跟你合作」的規則檔 |
| **② 給它記憶** | 建資料夾、每日日誌、記下你的檔案都放哪 | 它記得住跨天的事 |
| **③ 給它能力** | 把重複的事變成招式 | 它會做你教它的流程 |

跑完第一段就停下來，用一個禮拜，再決定要不要往下。

## 跑完之後，最重要的一件事

**關掉對話，重新開一個。**

然後隨便問它一句話——你會發現它講話的方式變了。

因為它每次開始工作，都會先讀那份檔案。

## 常見問題

**我一定要先建好資料夾嗎？**
不用。你隨便放哪裡都可以開始——工程師會問你的英文名，然後幫你建 `你的名字-agent` 資料夾，再帶你搬過去。

**為什麼中間要換一次資料夾？**
因為你的分身要住在自己的資料夾裡。工程師一開始是在你原本開的地方跟你講話，建好新家之後得請你走進去——它會給你一句話複製貼上，接得上進度，不用重講。

**我原本就有 CLAUDE.md，會被蓋掉嗎？**
不會。腳本會先確認那個檔案是不是它自己——如果是你原本寫的內容，它會接在後面並用標記包起來，不會動你的東西。

**Claude Code 跟 Codex 都能用嗎？**
可以，兩個檔案內容一樣。腳本會自己判斷環境。

**資料夾可以用中文名字嗎？**
建議不要。多數時候能用，但一旦出問題（某個工具不支援、換到 Windows、上傳到網路）會很難查。用英文最保險。

**每次都要重貼檔案路徑給 AI，很煩怎麼辦？**
第二階段會建一份「我的東西都放哪」清單。你講一次，它記下來——之後說「幫我看某某專案」它就知道去哪找。

**做到一半沒時間了怎麼辦？**
直接關掉就好，**不用再丟一次這份檔案**。

tt 第一段就會把自己複製成 `tt-script.md` 留在你的資料夾裡，進度寫在 `onboarding.md`。
你下次在那個資料夾開 AI，它會自己說「你的分身還有幾段沒設定完，要接著做嗎？」——說「好」就接下去。

（真的把 `tt-script.md` 刪掉了也救得回來：回這個 repo 下載 `CLAUDE.md`，改名成 `tt-script.md` 放回去，進度不會掉。）

**這份檔案寫完就結束了嗎？**
不是。你每次覺得「怎麼又來了」的時候，就是它該長大的時候——跟 AI 說「把這條加進規矩」就好。

**跑完會長出什麼資料夾？**
`CLAUDE.md`（規矩）、`memory/`（日記）、`knowledge/`（知識）、`raw/`（原料）、`workflows/`（流程）、`projects/`（以後每個專案員工住一間）、`onboarding.md`（進度表）。**每一個都是純文字，帶著走就能換工具。**

**知識庫會不會越放越亂？**
會，所以最後一段 tt 會教它「健檢」——檢查有沒有互相矛盾的筆記、沒人連到的孤兒頁、還有最重要的：**它的記憶檔有沒有停在三個月前**。之後你只要說「健檢一下」就會跑一遍。

**裝 MCP 那步失敗了怎麼辦？**
tt 會改成把設定內容印出來，請你複製貼上。**不會卡在那裡跟你說做不到。**
