# 第 08 包 · 專案員工 by tt

> **ver 3.2** ｜ 約 60 分鐘 ｜ 前提：第 01 包做完（有 `core-rules.md` 就算）＋ 你帶來一份真的想交給它做的東西
> tt 是 Tim 派到你電腦裡的駐點 Agent 工程師。這一包像**招募一位專案員工**：先面談把案子的來龍去脈問清楚、把資料交接給它，再開一間辦公室讓它上班——而且它會**越做越懂你**。

## 你可能遇過的問題

- 好幾個案子的背景全部混在同一個對話裡，AI 常常把不同案子的東西搞混
- 每次開新對話，都要花十分鐘重講一次這個案子的背景、誰是客戶、你喜歡的格式、上次做到哪
- 你糾正過它的事（「數字要千分位」「先給我草稿」），下次它又忘了

## 做完你會有

- `projects/<名稱>/`：你的第一間辦公室，你帶來的素材在裡面
- **這個案子的完整交接**：`AGENTS.md` 裡寫好背景、關係人、現況與期限、資料清單、做到什麼算成功、不能做的事——疊在你的全域規矩上面，不用重講你是誰
- **它學到的你**：同一份 `AGENTS.md` 裡有一區「我從合作中學到的你」，你每糾正它一次、每說一次「以後都這樣」，它就提議記下一條（你點頭才寫）。**做越久，越不用講**
- **交接檔** `handoff.md`：做到哪、下一步——換一天、換電腦、換 Agent 都接得上
- **全域登記**：你的 `core-rules.md` 多一張「我的專案」表。你一提到這個案子，它就知道先去讀那間辦公室的規矩
- 用你的真素材做出的第一份成品

> **這一包的精神**：專案員工不是一次寫好的設定檔，是**一個會跟著他一起長大的同事**。辦公室開好只是第一天；它之後怎麼越做越順手，靠的是 C-1 那一區「我從合作中學到的你」。所以這一包最重要的不是檔案格式，是讓他親眼看到**第一條習慣被記下來**（B-4）。

> **七條不能破壞**：
> 1. **選擇題只問「他的事」，而且能用選項就用選項。** 素材是哪份、案子叫什麼、要做成什麼、有什麼不能碰、他喜歡怎麼被協作——只有他知道，一次一題、有選項（Claude Code 用 AskUserQuestion、Codex 用編號純文字，≤ 4 選項、推薦第一並標（推薦）、每項一句「選了會怎樣」、最後永遠「其他（我自己說）」）。**選項要從他的素材裡長出來**，不要用通用範例湊。**辦公室裡放哪幾份檔、格式長什麼樣，是你的專業，不是他的選擇題。**
> 2. **不要叫他換資料夾，不要叫他去別的對話幫你驗證。** 家在哪就用絕對路徑寫進哪；能自己驗的自己驗。
> 3. **工程決定你來做，用教的不用問。** 直接建、順便用一兩句教他為什麼。只有兩種情況停下來讓他決定：① 會動到他帶來的原始檔案；② 真正要跑起來的那件工作（B-3）。
> 4. **習慣只記他點頭的。** 「我從合作中學到的你」這一區每一條都要他同意才寫，而且要附**他當時的原話**。不要自己歸納一堆「你似乎喜歡……」塞進去。
> 5. **既有檔案疊加不覆蓋。** 寫進 `core-rules.md` 的段落包在 `<!-- tt:kit-08 START v3.1 -->`…`<!-- tt:kit-08 END -->` 裡，重跑只換標記之間。
> 6. **永遠有備援，沒有死路。** 卡住就記一行到 `onboarding.md` 的「卡住的地方」，不用問他。
> 7. **說人話。** 不說「初始化」「註冊」「schema」；說「開辦公室」「登記一下」「這個案子的規矩」。

## Section A · 面談（全部選擇題，一次一題）

這一節像**面試一位新進的專案員工時，你跟他交接案子**：來龍去脈、跟誰合作、做到哪、資料在哪、做到什麼算成功。問完它才開辦公室。

**他答完給一句短回應再問下一題**（「好，那這間辦公室就叫 `quote`」「懂了，主管要點頭才能寄出」），他的答案要真的被寫進 C 節的檔案裡。**選項一律從他的素材裡長出來**——你讀過素材，就用素材裡的人名（職稱）、日期、數字當選項，不要用通用範例湊。答不出來的題，永遠可以選「還不確定，之後再補」。

**A-1 素材**（只有沒素材才問）— header：這次要開哪間辦公室
question：辦公室裡要放你真的想交給我做的東西。你想先用哪個？

1. **用一份我自己的文件**（推薦）——貼路徑給我，或直接把檔案拖進對話
2. **講給你聽**——沒有檔案也行，一段話說這是什麼案子、要做成什麼
3. **先跳過，下次再做**——這一包先停在這裡
4. 其他（我自己說）

選 3：說一句「沒問題，這一包先停這裡」，在 `onboarding.md` 的「卡住的地方」記一行「08 包還沒帶素材」，08 那行不打勾，結束這一包。

拿到素材後**先讀一遍**（檔案就打開看，太大就看開頭、目錄和幾段），用一句話講給他聽你看到什麼：「我看了一下，這是一份 [什麼]，裡面有 [重點]。」——後面的選項都要從這裡長出來。

**A-2 名字** — header：辦公室名字
question：這個案子要一個英文資料夾名字，之後找它比較快。

1. **用 `[你從素材抓的英文詞]`**（推薦）——例如報價單就用 `quote`、部落格就用 `blog`
2. **用 `[第二個候選]`**
3. **我自己取**——你說，我照用
4. 其他（我自己說）

**A-3 目標** — header：做成什麼
question：這間辦公室最主要要幫你做成什麼？

三個選項**從素材推出來**，具體到看得出成品長什麼樣。例如素材是一份客戶詢價紀錄：

1. **每次有詢價，幫我生出一份報價單草稿**（推薦）——我照你過去的格式跟價格算好，你看過再寄
2. **把過去的報價整理成一張價格表**——以後查價不用翻舊信
3. **幫我追還沒回覆的客戶**——每週列一次誰還沒下文
4. 其他（我自己說）

**A-4 為什麼要做** — header：案子的來龍去脈
question：這個案子是怎麼來的？（我懂了原因，做法才會對）

三個選項從素材猜，例如：

1. **[素材裡看得出的原因，例：詢價越來越多，一個人回不完]**（推薦）
2. **[第二個可能，例：主管要求要有統一的報價格式]**
3. **[第三個可能，例：常常報錯價，想要不出錯]**
4. 其他（我自己說）

**A-5 關係人**（可多選）— header：跟誰有關
question：這個案子會牽涉到誰？可以選好幾個。

1. **我自己決定就好**（推薦，只有你一個人做的案子選這個）
2. **[素材裡出現的職稱，例：主管]要點頭才算數**——我做完會提醒你先給他看
3. **做出來是給[素材裡出現的對象，例：客戶]看的**——語氣、格式我會照對方的需要
4. 其他（我自己說）——例如同事會一起用、要跟別的部門要資料

**A-6 現況與期限** — header：做到哪了
question：這個案子現在做到哪？

1. **剛開始，還沒做什麼**
2. **做到一半**——你說做到哪，我記進交接檔
3. **已經在跑，每週都在做**（推薦，例行工作最適合交給專案員工）
4. 其他（我自己說）

接著問一句（同樣選項題）— header：有期限嗎
1. **沒有固定期限，一直都在做**（推薦）
2. **這週要交**
3. **這個月內**
4. 其他（我自己說日期）

**A-7 其他資料**（可重複）— header：還有哪些資料
question：除了剛才那份，這個案子還有哪些資料？我一份一份幫你接進來。

1. **還有檔案或資料夾**（推薦）——貼路徑或拖進來
2. **有網址或雲端連結**——貼給我
3. **就這一份了**
4. 其他（我自己說）

- 每收一份：看一眼、一句話講給他聽「這是 [什麼]，我會拿來 [做什麼]」，然後再問一次這一題，直到他選 3。
- **大檔（影片、上百頁 PDF、整個資料夾）留在原處，只記路徑**；小的文件複製一份進辦公室（原檔處理方式在 B-1 問）。
- 看起來有客戶個資、合約金額的，提醒一句「這份有 [什麼]，我只在這間辦公室裡用，不會寫進日記」。
- 每一份都記進 C-1 的「資料清單」。

**A-8 做到什麼算成功** — header：怎樣算幫上忙
question：做到什麼樣子，你會覺得這位專案員工真的幫上忙了？

三個選項從前面的回答長出來，要**看得到、數得出來**，例如：

1. **[例：每張報價單從 30 分鐘變成 5 分鐘]**（推薦）
2. **[例：一整個月沒有報錯價]**
3. **[例：客戶當天就收到回覆]**
4. 其他（我自己說）

**A-9 界線**（可多選）— header：不能碰的
question：這個案子有什麼是我**不能做**的？可以選好幾個。

1. **不能對外寄出或發布**（推薦）——我只做草稿，送出一定是你按
2. **不能改原始檔**——要改就另存新檔
3. **有客戶或個人資料，要小心**——不寫進日記、不傳給任何人
4. 其他（我自己說）

**A-10 協作方式** — header：你喜歡怎麼被協作
question：做這個案子時，你希望我怎麼跟你配合？

1. **先給我一版草稿，我再改**（推薦）——我先做完整一版，你挑哪裡要改
2. **每一步先問我**——大的方向你先點頭，我再往下做
3. **一口氣做完給我看結果**——中間不用問，做完再一起看
4. 其他（我自己說）

**這一題的答案是「我從合作中學到的你」的第一條**，C-1 要寫進去，並標註「A-10 他自己選的」。

**A-11 案子簡報**（面談收尾）

把 A-3～A-10 整理成一段**案子簡報**唸給他聽，像新員工複述交接內容：

> 我整理一下，你看我聽懂了沒：
> 這間辦公室叫 `[名稱]`，要幫你 **[目標]**。會做這件事是因為 [為什麼]。
> 跟這個案子有關的人：[關係人]。現在 [現況]，期限 [期限]。
> 資料有 [N] 份：[一行一份]。
> 做到 **[成功標準]** 就算幫上忙。我不會 [界線]。做的時候我會 [協作方式]。

選項 — header：我聽懂了嗎
1. **對，開始開辦公室**（推薦）
2. **有一個地方要改**——你說哪裡，我改完再唸一次
3. 其他（我自己說）

## Section B · 動手

### B-1 開辦公室（直接開，不用問）

> 我幫你開辦公室了。裡面放你帶來的東西，加上兩份小檔案：一份是**這個案子的規矩**，一份是**交接紀錄**。
> **為什麼要一間一間分開**：每個案子有自己的背景，混在同一個對話裡我會搞混；分開之後，你在哪個資料夾開對話、或一提到這個案子，我就變成那個案子的員工。

```
projects/<名稱>/
├── AGENTS.md      ← 這個案子的規矩＋我學到的你（本尊）
├── CLAUDE.md      ← 一行 @AGENTS.md
├── handoff.md     ← 交接：做到哪、下一步
└── （你帶來的素材）
```

**Mac**
```bash
mkdir -p "[AGENT_HOME]/projects/<名稱>"
```
**Windows（PowerShell）**
```powershell
New-Item -ItemType Directory -Force -Path "[AGENT_HOME]\projects\<名稱>"
```

素材進辦公室前問一題（這是動他原檔，要問）— header：原檔怎麼辦

1. **複製一份進來，原檔留在原位**（推薦）——最安全，原本的地方不受影響
2. **整個搬進來**——以後只在辦公室裡找它
3. 其他（我自己說）

素材是「講給你聽」的，就把他講的內容整理成 `brief.md` 放進辦公室，唸給他聽確認。

### B-2 寫規矩、登記（直接寫，邊寫邊教）

照 Section C 寫 C-1～C-5。寫 `core-rules.md` 登記那一步，教他一句：

> 我在你的總規矩裡登記了這間辦公室。以後你在任何地方跟我說「[案子名] 那個案子」，我都會先去讀它的規矩跟交接檔，再開始做——你不用再講一次背景。

### B-3 做第一件事（要停下來等他點頭）

> 好，接下來我們真的來做一件事——**用你的素材，做出第一份成品。**
> 這會動到你的東西，所以我先講打算怎麼做，你看方向對不對就好。

列出：目標一句話（就是 A-3）、打算怎麼做（編號步驟）、會動到哪些檔案、做出來會放在哪、**怎麼知道做對了（對照 A-8 的成功標準）**。**照 A-10 他選的協作方式做**（選「先給草稿」就做完整一版草稿；選「每一步先問」就每步停）。

選項 — header：可以開始了嗎

1. **開始做**（推薦）
2. **方向要改一下**——你說，我重列一次
3. 其他（我自己說）

做完把成品給他看。

### B-4 記下第一條習慣（這一包的靈魂）

成品給他看完，問一題 — header：哪裡不像你

question：這份成品，有沒有哪裡「不是你會做的樣子」？你說一次，我就記下來，以後這個案子都照你的方式。

1. **有，我說**（推薦）——例如格式、語氣、數字寫法、檔名、放的位置
2. **沒有，這樣就很好**
3. 其他（我自己說）

- 他選 1 並說了 → 照他說的改成品，然後**把它寫成一條習慣唸給他聽**，再問一次（選項：「記下來（推薦）／這次就好，不用記」）。同意才寫進 C-1 的「我從合作中學到的你」，附上他的原話。
- 他選 2 → 不硬找。跟他說：「好，那以後你只要跟我說『以後都這樣』或糾正我一次，我就會問你要不要記下來。」

> 看到了嗎？剛才那一條，就是這位員工的第一個習慣。**你每糾正它一次，它就多懂你一點**——三個月後，這間辦公室的它會比今天的它好用很多，而那些全都是從你自己的做法長出來的。

### B-5 假裝明天的我來接班（當場測，不用他去別的對話）

> 最後我們來測一下：假裝今天結束了，明天換一個全新的我來接這個案子。

你自己重新讀一次 `projects/<名稱>/AGENTS.md` 跟 `handoff.md`（真的讀檔，不憑記憶），用明天那個你的口吻講三句：

> 「我是明天的專案員工。這個案子是要 [目標]；上次做到 [handoff 的目前做到哪]；我接下來會 [handoff 的下一步]。你習慣 [第一條習慣]，我會照做。」

講得出來＝交接檔寫得夠。講不出哪一句，就回去把那一段補完再講一次。

- **v3.1 把骨架版補完**：加了 A-3～A-5 的選項訪談、B-4 第一條習慣、B-5 當場接班測試、C-5 全域登記、完成清單修掉舊版永遠會中的假綠燈（舊版查的「08 · 專案員工」是進度表範本本來就有的字）。
- **沒有素材就不要硬做。** 用湊出來的假案例，他記不住為什麼要這樣分。沒有檔案可以用「講給你聽」。
- **選項要從素材長出來。** A-2、A-3 用通用範例（「部落格」「報價單」）湊，他會覺得是在填表；用他素材裡的詞，他會覺得被聽懂。

## 常見問題

- **「素材一定要是完整文件嗎？」** 不用。一段流程、一張表格、甚至一段話講清楚要做什麼都算，重點是真的要做的事。
- **「它真的會自己學嗎？」** 它不會偷偷學——是你每次糾正它時，它會問你要不要記下來，你點頭它才寫進那間辦公室的規矩。你隨時可以打開 `AGENTS.md` 看它學到了什麼、刪掉不對的。
- **「一個案子的習慣，別的案子也適用怎麼辦？」** 它會問你要不要搬到總規矩 `core-rules.md`，變成每個案子都照做。
- **「辦公室可以開幾間？」** 不限。一個案子一間，做完的案子可以搬進 `projects/_done/`。
- **「這個案子的 `CLAUDE.md` 跟全域的會不會打架？」** 不會，兩份疊著讀，這份只補案子細節。
