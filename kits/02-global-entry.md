| 環境 | 全域位置 | 放什麼 |
|---|---|---|
| Claude Code | `~/.claude/CLAUDE.md` | `@[AGENT_HOME]/core-rules.md` |

```bash
# Mac
mkdir -p ~/.claude ~/.codex
```
```powershell
# Windows
New-Item -ItemType Directory -Force -Path "$env:USERPROFILE\.claude","$env:USERPROFILE\.codex" | Out-Null
```

備援：`mkdir` 或寫檔失敗（沒有權限、他不讓你動家目錄）→ **把兩個檔案的內容印出來請他自己貼**。四件事一次講完：

> **目標**：把這兩段貼到兩個隱藏資料夾裡。
> **步驟**：
> 1. Mac：Finder 按 Cmd＋Shift＋G，輸入 `~/.claude`／Windows：檔案總管網址列輸入 `%USERPROFILE%\.claude`
> 2. 在裡面建一個 `CLAUDE.md`，貼上第一段
> 3. 同樣方式到 `.codex`，建 `AGENTS.md`，貼上第二段
>
> **回來說什麼**：貼好了說「貼好了」
> **做不到怎麼辦**：跟我說「貼不了」，我們跳過這一包，你的分身在 `[AGENT_HOME]` 裡照樣認得你

**這句要講，因為他可能在別的地方看過 symlink 的做法：**

### 兩層規則檔：這就是「員工模式」

**現在他有全域了，才講得動這件事。**

> 規則檔有兩層，會**疊加**在一起：
>
> | | 放什麼 | 什麼時候生效 |
> |---|---|---|
> | **全域** | **這個人是誰** — 你的身份、講話方式、價值觀、專業 | 你在任何資料夾工作都生效 |
> | **專案** | **這個案子的規矩** — 這個專案怎麼做、有什麼慣例 | 只在那個資料夾生效 |
>
> 兩份加起來，就是一個**「在這個專案上工作的員工」**。
>
> 而且是**一層一層往下疊的**——資料夾裡面還有資料夾，每一層都可以放一份，全部會加起來。

舉個例子讓他有畫面：

> 比方說你之後要做一個「幫我處理客戶信件」的員工：開一個資料夾、寫一份專案規則檔說明客戶是誰、回信的分寸在哪。
>
> 那個員工一樣認得你（因為全域那份），但它多了處理信件的規矩。

**但要擋住他現在就想開一堆資料夾**——這是新手最常見的浪費：

> 不過**你現在還不需要開任何專案資料夾**。三個訊號出現才開：
>
> 1. 這個案子的**資料量大到**每次都要重新交代一遍背景
> 2. 有一些**只有這個案子適用的 know-how**，寫進全域會污染別的工作
> 3. 你發現自己在同一件事上**重複糾正我三次以上**
>
> 三個都沒出現就先不要開。**空資料夾不會讓你變厲害，只會讓你以為自己在進步。**
>

## 踩坑紀錄（給 Tim）

- **`~` 是最常見的失敗點**：全域入口載入時的工作目錄不固定，`~` 展不開就整份讀不到，而且**完全不會報錯**——學員只會覺得「怎麼沒效果」。所以 Section E 專門檢查這件事。
- **帶他看，不要用講的**：隱藏資料夾這件事用講的沒有感覺，`ls` 跑出來擺在眼前才有。
- **既有內容一定要備份＋唸出來**：那兩個位置常常已經有東西（尤其重度使用者），直接覆蓋等於毀掉他的設定。唸出來再問，比直接問「要不要併」清楚很多。
- **驗證不能外包**：舊版叫學員「去別的資料夾開對話測」，很多人一關掉就回不來了。tt 自己讀回來、自己從那個路徑讀 `core-rules.md`，魔術降級成選做。
- **員工模式放最後講**：他有全域了才聽得懂「兩層疊加」。同時要擋住他馬上開一堆空資料夾。
- **純工程動作不要做成選擇題**：舊版 A-2 問「要不要我把那兩個位置接回你的規則檔」——他還沒看過那兩個檔案，這題等於沒有選項。改成 tt 講一句「為什麼要這樣做」然後直接接；他自己說不要才停。整包唯一保留的選擇題是 A-3（那兩個位置原本就有他的內容）。

## 常見問題

- **我沒有 `.codex`／沒有 `.cursor`，正常嗎？** 正常，你沒裝那個工具而已。看到幾個就處理幾個，兩個資料夾我會自己補。
- **那兩個位置原本的內容會不見嗎？** 不會。我先備份成 `.bak`，你選要不要併進 `core-rules.md`。
- **可以只接一個嗎？** 可以，你只用一個平台就只接那一個。兩個都接的好處是換工具不用重教。
- **我以後改 `core-rules.md`，全域會跟著變嗎？** 會。全域那兩個檔案只是指標，內容永遠以 `core-rules.md` 為準。
- **我把 `[AGENT_HOME]` 搬家了怎麼辦？** 跟我說新路徑，我把那兩個入口的路徑改掉就好，其他不用動。
